How the status is set

  • GOn trackForecast finish is no more than 5 working days after the baseline finish.
  • AAt riskForecast finish is 6 to 15 working days after the baseline, or nothing has been logged for more than 5 working days that had work planned.
  • ROff trackForecast finish is more than 15 working days after the baseline.

The forecast takes what the Install Log says has actually been done and runs the rest of the plan at the pace achieved over the last 10 working days that had work planned or logged, the same as on each programme's dashboard. Until anything is logged, the planned finish is used. Programmes in planning aren't rated.

Export

Save this overview and both programme dashboards as one web page file, with all the figures built in: every building and area, the charts, the Install Logs, and an Excel summary for each programme. The file doesn't need the spreadsheets, the internet or any other file, so it opens in a browser wherever it's kept: downloaded from SharePoint or Teams, synced with OneDrive, or attached to an email. It doesn't update itself, so download a new one after the planners are updated.

Each programme's figures come from its spreadsheet in this folder, read when the page opens, so they are as current as the last upload. Working days are Monday to Friday, leaving out bank holidays and the Christmas break.
